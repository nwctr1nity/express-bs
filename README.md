# Экспресс БС

Сайт продажи нерудных материалов (песок, щебень, галька) с калькулятором заказа.
Стек как у booking-pwa: React 19, Vite, TypeScript. Хостинг: Vercel (vercel.json).

- `pnpm install && pnpm dev` — разработка
- `pnpm build` — сборка в `dist/`
- Цены, телефоны, зоны доставки: `src/data.ts`
- Фото: `public/photos/` (WebP, `-sm` — уменьшенные)

Заявки уходят в WhatsApp (+7 777 149 76 27) с готовым текстом, сервер не нужен.
